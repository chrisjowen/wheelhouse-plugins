# Wheelhouse plugins

The official plugins registry for [Wheelhouse](https://github.com/chrisjowen/wheelhouse).

Wheelhouse's Plugins view reads `wheelhouse-registry.json` from this repository to list plugins you can install. Each entry points at the repository the plugin installs from.

To list a plugin, add an entry to `wheelhouse-registry.json` in a pull request. The manifest format is documented in the Wheelhouse repository (`docs/plugin-registry.md`).
